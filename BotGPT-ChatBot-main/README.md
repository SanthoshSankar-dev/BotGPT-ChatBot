## 🚀 Getting Started

### Prerequisites

* Node.js (v20 or higher)
* Google AI Studio API Key

### Installation

```bash
git clone https://github.com/SanthoshSankar-dev/BotGPT-ChatBot.git
cd BotGPT-ChatBot
npm install
```

### Environment Setup

Create `.env`

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```

### Run Project

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
